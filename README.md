# Джарвис

Голосовой ассистент для Windows (русский язык): запускает игры и программы, открывает сайты,
включает треки в YouTube Music, ведёт заметки.

## Запуск на любом ПК

```
git clone <репозиторий>
cd jarvis
start.bat
```

При первом запуске `start.bat` сам создаст `.venv` и поставит зависимости (нужен Python 3.10+).

Что найдено на этом ПК, покажет:

```
.venv\Scripts\python jarvis.py --check
```

## Сборка в exe

```
build_exe.bat
```

Получится `dist\Jarvis.exe` (без консоли, с иконкой `jarvis.ico`; файл должен лежать рядом с `build_exe.bat`). Особенности:

- `config.json` кладётся **рядом с Jarvis.exe**, а не внутрь сборки: путь определяется по самому exe.
- Ошибки пишутся в `%USERPROFILE%\.jarvis\errors.log`, так как консоли нет.
- «Что ты умеешь» открывает `commands.txt` в блокноте, `Jarvis.exe --check` покажет `check.txt`.
- Готовый exe можно запускать на другом ПК без Python, пути определятся там заново.
- Если exe блокирует антивирус или SmartScreen, это типичная реакция на PyInstaller и `pyautogui`.
  Тогда запускайте через `start.bat`.

## Голос и нейросеть

Джарвис говорит **живым нейроголосом Piper** (офлайн, без интернета после первой загрузки).
При первой реплике модель (~63 МБ) сама скачивается в `%USERPROFILE%\.jarvis\voices`.

Живые голоса на выбор: `dmitri` (мужской, по умолчанию), `ruslan` (мужской, спокойный),
`irina` (женский), `denis` (мужской). Смена: окно настроек → вкладка «Общие» → «Живой голос»,
или `config.json → voice.piper_voice`. Движок переключается там же (`voice.engine`: `piper` / `sapi`).

Проверить голос: кнопка **«Проверить голос»** в настройках (вкладка «Общие»)
или `.venv\Scripts\python jarvis.py --say "проверка"`. Список голосов: `--list-voices`.
Запасной голос — Windows SAPI. Если звука нет, причина записана в
`%USERPROFILE%\.jarvis\errors.log`.

**Нейросеть** отвечает на вопросы голосом и коротко: «Джарвис, какую игру мне лучше поиграть?», «Джарвис, какая сегодня погода?».

1. Открой настройки → вкладка **Нейросеть**, нажми «Получить ключ» (Gemini: Google AI Studio, карта не нужна) и вставь ключ.
2. Нажми «Проверить», затем «Сохранить» и включи переключатель.
3. Говори фразу со словом «Джарвис». Без обращения нейросеть молчит, чтобы разговоры рядом не тратили лимит бесплатного тарифа.

Нейросеть знает твой ПК: видеокарту, процессор, память, список установленных игр Steam и то, когда ты в них играл, время
и режим (игровой/учебный). Погоду берёт из Open-Meteo (бесплатно, без ключа) по городу из настроек.
Если не хочешь передавать данные о ПК, выключи переключатель «Рассказывать нейросети про мой ПК».

Фразы-команды («открой ютуб», «запусти кс2») работают как раньше: вопрос уходит нейросети, только если он начинается
с вопросительного слова («какой», «что», «как», «расскажи»…) или Джарвис не нашёл такой команды. Проверить из консоли:
`.venv\Scripts\python jarvis.py --ask "какая сегодня погода"`.
**Додумывание непонятых фраз** (переключатель «Додумывать непонятые фразы» на вкладке **Нейросеть**): если распознавание
не нашло команду, Google вернул искажённый текст или фразу без знаков препинания — нейросеть один раз исправляет её
(ошибки слов, запятые) и Джарвис повторяет разбор. Срабатывает только для фраз со словом-активатором/обращением либо
похожих на команду (чтобы разговоры рядом не тратили лимит), таймаут 4 с; при недоступности нейросети фраза
обрабатывается как раньше. В диктовке («надиктуй …») нейросеть дополнительно расставляет знаки препинания.

Ключ сохраняется в `%USERPROFILE%\.jarvis\config.json` открытым текстом, не выкладывай этот файл. Ключ можно задать и
переменной среды `JARVIS_AI_KEY`. Бесплатные тарифы имеют лимиты запросов и меняются, актуальные значения смотри у провайдера.
У бесплатного Gemini вне ЕС запросы могут использоваться для обучения моделей.

## Файлы, саморедактирование, напоминания и история запросов

Нейросеть может работать с файлами на ПК — спроси голосом, например: «Джарвис, создай файл список.txt на рабочем столе
с записями покупок», «Джарвис, что в папке Документы», «Джарвис, замени в jarvis.py число 400 на 500».
Простые случаи работают **без нейросети** (локальная команда): «создай файл отчёт», «создай папку игры»,
«создай папку моды и в ней файл список» — по умолчанию на рабочем столе, место можно назвать
(«в загрузках», «в документах»). Инструменты модели (вкл./выкл. настройками → вкладка **Нейросеть**):

| Инструмент | Что делает |
|---|---|
| `list_dir` | список файлов и папок по любому пути (все диски) |
| `read_file` | чтение текстового файла (при необходимости — с нужной строки) |
| `find_files` / `find_any` | поиск по маске в папке / по названию по всему ПК («где файлы из колледжа») |
| `open_path` | открыть файл или папку в Проводнике («открой папку с фотографиями») |
| `write_file` | создание файла, перезапись или дописывание в конец (папки создаются сами) |
| `edit_file` | замена фрагмента текста; перед правкой создаётся копия `.bak` |
| `delete_path` | удаление файла/папки в корзину — только по прямой просьбе «удали …» |
| `sensors` | температура и загрузка процессора/видеокарты, ОЗУ, диски («это норма?» — по нормам из промпта) |
| `steam_find` / `steam_install` / `steam_launch` | установка и запуск игр («установи wukong», дальше — «запусти вуконг») |
| `add_game` / `add_site` / `add_command` | дописать игру, сайт или команду в настройки — и работают голосом |
| `add_reminder` / `list_reminders` / `delete_reminders` | напоминания |
| `type_text` | набор текста в активном окне с авточисткой речи («напечатай …») |
| `read_history` | чтение истории запросов («что я тебя просил вчера?») |

Ограничения: в системные папки Windows (`System32`, `Boot`, `WinSxS`…) писать нельзя,
удаление — только в корзину (можно восстановить) и только когда прямо просят,
за один вопрос — не больше шести вызовов инструментов. Если провайдер не поддерживает вызов инструментов,
Джарвис просто ответит текстом, как раньше. Пути в голосовых ответах не проговариваются —
только в окне уведомления.

**Удаление голосом**: «удали файл отчёт», «удали папку моды в загрузках» (файлы уходят в корзину,
можно восстановить), «удали команду блокнот» / «удали игру …» / «удали сайт …» (убирает свои команды
из настроек). Находит файл по ненадёжному совпадению (ищет в папке-поиске и в «Документы»/«Загрузки»:
«new file» совпадёт с «new_file.txt»), спрашивает уточнение, если нашлось несколько, и кладёт
найденный объект в корзину Windows — даже если путь содержит кавычки, апострофы или кириллицу.

**Умная диктовка**: «надиктуй привет точка как дела вопрос» — Джарвис почистит речь
(убирает «э-э», «ну», «типа», чинит «што»→«что», «щас»→«сейчас»), расставит знаки по голосовым
командам («точка», «запятая», «восклицательный знак», «новая строка», «новый абзац», кавычки, скобки)
и вставит готовый текст в активное окно (например, в чат Telegram, поле Chrome, Word, блокнот).
Пауза `delay_sec` даёт кликнуть в нужное окно, `paste_delay` — дождаться, пока окно успеет
забрать буфер; при малом `paste_delay` вставляется только начало текста. Буфер обмена после
вставки восстанавливается (переключатель в настройках — включён по умолчанию). Работает в любом окне:
блокнот, браузер, Word, чат. Использует EN-раскладку для Ctrl+V, иначе на русской раскладке
клавиша V превращается в М и ничего не вставляется.

**Напоминания**: «напомни забрать дейлики через 10 минут», «напомни выключить компьютер в 20:00»,
«каждый день в 9:00 напомни позвонить маме». Фоновая проверка каждые 10 секунд, срабатывание — голосом.
«Напоминания» — показать список, «очисти напоминания» — удалить все. Сложное время можно поставить
через нейросеть («Джарвис, напомни мне в пятницу в 18:00 …»). Файл: `%USERPROFILE%\.jarvis\reminders.json`.

**Саморедактирование**: переключатель «Разрешить нейросети редактировать самого Джарвиса» даёт модели доступ
к `jarvis.py`, `jarvis_ai.py`, `jarvis_settings.py` и `config.json`. Правка конфига подхватывается сразу,
правка кода — после перезапуска. **В собранном exe** код лежит внутри, поэтому `build_exe.bat` кладёт копию
исходников в `dist\src\`: Джарвис редактирует её, а пересборка делается запуском `build_exe.bat`
(нужен Python). Настройки, игры, сайты, команды и напоминания в exe переживают любые правки — они в
`%USERPROFILE%\.jarvis\`.

**История запросов** пишется в `%USERPROFILE%\.jarvis\history.jsonl` (время, вопрос, ответ, какие файлы
менялись), нейросеть может её читать инструментом `read_history`.
Команды: **«история запросов»** — сохранить последние двадцать в `%USERPROFILE%\.jarvis\history.txt`
и открыть их в Блокноте, **«очисти историю»** — удалить журнал. Лимит и включение задаются
в настройках (`history.max`, `history.enabled`).

## Поиск в Google

Скажи **«загугли …»** или **«найди …»**, и в Chrome (основной профиль) откроется поиск Google по этому запросу.
Подойдёт и «найди в интернете …». Примеры: «загугли рецепт борща», «найди погоду в Днепре».
«Найди трек …» по-прежнему включает музыку, а не ищет в Google.

## Настройки

Скажи **«открой настройки»**, откроется окно (сделано на `customtkinter`, тёмная тема). Всё, что в нём сохранено, применяется сразу, без перезапуска. В таблицах есть поиск, у каждой записи кнопки ✎ (изменить, или двойной клик) и ✕ (удалить). `Ctrl+S` — сохранить.

| Вкладка | Что там |
|---|---|
| Мои команды | Фраза → ссылка, путь к программе/папке или команда (`notepad.exe`). «Обзор…» выбирает файл |
| Игры Steam | Фраза → Steam appid |
| Сайты | Фразы для «открой …» |
| Ссылки | Фильмы, аниме, GitHub, комплектующие, Classroom, Logika, Roblox |
| Нейросеть | Провайдер (Gemini / Groq / OpenRouter / свой), API-ключ, модель, город для погоды, доступ к файлам, саморедактирование, история запросов, кнопка «Проверить» |
| Общие | Голос, задержка выключения, слово-активатор, профили Chrome, задача планировщика для Genshin, **автозапуск Джарвиса**, фразы паузы и режимов |
| Пути | Ручные пути к программам, если автопоиск не нашёл |

Свои команды проверяются раньше встроенных: если фраза совпадёт со встроенной («музыка»), сработает твоя.

### Где хранятся настройки

`%USERPROFILE%\.jarvis\config.json` (папка доступна для записи всегда, настройки переживают пересборку exe и
обновление проекта из git). Рядом лежат `notes.txt`, `errors.log` и журнал `history.jsonl`.

Файлы читаются по очереди, следующий перекрывает предыдущий:
`config.json` рядом с программой → `~/.jarvis/config.json` → файл из переменной `JARVIS_CONFIG`.
Окно настроек пишет в `~/.jarvis/config.json` (или в `JARVIS_CONFIG`, если она задана).
Чтобы перенести настройки на другой ПК, скопируй этот файл.

Списки «Мои команды», «Игры Steam» и «Сайты» заменяют значения по умолчанию целиком. Благодаря этому удалённая
запись не возвращается. Остальное (голос, пути, ссылки) дополняет умолчания.

`config.example.json` — шаблон для ручной правки (например, чтобы положить свои Classroom/Logika в `config.json` рядом
со скриптом). Не указанные в нём ключи берутся по умолчанию. Дополнительно можно задать `voice.id` и `voice.rate`
(список голосов: `jarvis.py --list-voices`). В окне этих двух полей нет.

## Автозапуск через Планировщик заданий

Во вкладке **Общие → Планировщик заданий Windows** есть два переключателя:

- **Запускать Джарвиса при входе в Windows**: создаётся задача `JarvisAutostart` (запуск через 10 секунд после входа).
  В собранном exe она запускает `Jarvis.exe`, при запуске из исходников — `pythonw.exe jarvis.py` из `.venv`.
- **С правами администратора (без запроса UAC)**: задача идёт с высшими правами, поэтому Джарвис стартует без окна UAC
  и может запускать программы, которым нужен админ. Создать такую задачу можно только с подтверждением UAC: окно появится
  один раз, при нажатии «Сохранить».

Если exe потом переместить, окно настроек покажет предупреждение: нажми «Сохранить», и путь в задаче обновится.
Выключить автозапуск можно тем же переключателем (задача удаляется).

Джарвис не даст запустить себя вторым экземпляром (например, из планировщика и вручную одновременно).

Скрипт, который создаёт задачу, лежит в `%USERPROFILE%\.jarvis\autostart.ps1`. Проверить задачу можно в «Планировщике заданий» (`taskschd.msc`).

## Как определяются пути

- **Chrome** — реестр (App Paths), Program Files, LocalAppData.
- **Discord** — через `Update.exe --processStart`, версия `app-X.Y.Z` не важна.
- **Steam** — реестр; игры запускаются через `steam://rungameid/<id>`.
- **Telegram, Minecraft, Prism, Genshin** — типовые папки на всех дисках.
- **YouTube Music** — ярлык PWA из меню «Пуск», иначе Chrome `--app`.
- Нет Chrome — ссылки открываются в браузере по умолчанию.

## Безопасность

- Выключение и перезагрузка идут с задержкой (по умолчанию 15 с), «отмена» их останавливает.
- «Выход» срабатывает только на целое слово, не на «выходной».
- Распознавание речи идёт через Google (онлайн): всё, что слышит микрофон, уходит на сервер.
- Вопросы к нейросети (и данные о ПК, если включено) уходят выбранному провайдеру.
  Включи `wake_word`, чтобы команды выполнялись только после «Джарвис».

## Голосовой пакет: ПК, медиа и продуктивность

Новые команды работают в Windows 10/11 и не блокируют распознавание: работа с сетью,
процессами и тестами выполняется в фоне.

| Группа | Примеры фраз |
|---|---|
| ПК | «громче», «поставь громкость на тридцать», «яркость 70», «заблокируй ПК», «режим сна», «что грузит процессор», «сделай скриншот» |
| Приложения и медиа | «закрой блокнот», «пауза», «следующий трек», «что сейчас играет», «переключи звук на наушники», «браузер тише» |
| Время | «таймер на пять минут», «поставь будильник на 7:30», «засеки время», «сколько осталось», «отмени таймер» |
| Заметки и дела | «прочитай заметки», «прочитай последнюю заметку», «добавь в список дел купить молоко», «что в списке дел», «отметь выполненным 1» |
| Буфер и нейросеть | «прочитай буфер обмена», «прочитай выделенное», «переведи буфер на английский» |
| Интеграции | «доброе утро», «запусти тесты», «отправь в телеграм мама привет», «отправь в дискорд общий привет», «прочитай уведомления» |
| Игры | «брось d20», «брось 4d6 плюс 3», «подбрось монетку», «запиши последние тридцать секунд» |

### Диктовка

- Разово: «напечатай привет точка как дела вопрос» (старые алиасы `надиктуй`, `набери`,
  `вставь` сохранены).
- Непрерывно: «режим диктовки» или «диктуй»; завершение — «закончить диктовку» либо
  «стоп диктовка». В режиме слова «громче», «таймер» и «скриншот» печатаются как текст,
  а не выполняются как команды. По умолчанию режим выключается после 120 секунд тишины.
- Голосовые правки: «точка», «запятая», «вопросительный знак», «новая строка»,
  «новый абзац», «удали последнее слово», «отмени ввод».
- Ввод использует Unicode `SendInput`; для Windows Terminal/cmd/PowerShell и текста длиннее
  200 символов применяется вставка через временный буфер обмена. Введённый текст в историю
  записывается только как метка с числом символов, без содержимого.

### Настройки и хранение

В окно настроек добавлены вкладки **Безопасность**, **Уведомления**, **Интеграции**,
**Диктовка** и **История**. Можно менять положение/тему/длительность уведомлений без
перезапуска, горячую клавишу (по умолчанию `Ctrl+Alt+J`), координаты Open-Meteo,
команду тестов, чёрный список диктовки и парольную фразу.

Перед каждым сохранением пользовательского `config.json` делается копия в
`%USERPROFILE%\.jarvis\backups`; хранится до 20 последних копий. Команда
«восстанови настройки» возвращает последнюю копию после подтверждения. Парольная фраза
хранится только как salted SHA-256-хеш. Это защита от случайных голосовых срабатываний,
а не аутентификация и не биометрия.

Для сборки PyInstaller уже добавлены `--hidden-import`/`--collect-data` новых модулей.
При настройке через auto-py-to-exe используй те же hidden imports: `pycaw`, `comtypes`,
`psutil`, `screen_brightness_control`, `keyring`, `winsdk`, `jarvis_utils`,
`jarvis_system`, `jarvis_timers`, `jarvis_integrations`.

## Известные ограничения

- Диктовка работает в **большинстве обычных приложений** (Блокнот, Word, VS Code, Discord,
  Telegram, браузер, Windows Terminal), но не может вводить в окно от администратора, если
  Джарвис запущен без прав администратора (UIPI). Запусти Джарвиса от администратора через
  планировщик из вкладки «Общие».
- Игры с античитом, полноэкранные приложения, удалённые рабочие столы и виртуальные машины
  могут блокировать синтетический ввод. Для терминалов и длинного текста используется буфер,
  но это не гарантирует ввод в RDP/VM.
- Яркость поддерживается не всеми внешними мониторами. В этом случае Джарвис сообщит об
  ограничении драйвера/монитора.
- «Лайкни трек» и «добавь в плейлист» намеренно не нажимают элементы сайта наугад: разметка
  YouTube Music нестабильна. Команда честно сообщает о неподдерживаемом автоматическом UI.
- Game Bar по Win+Alt+G сохранит последние секунды только если фоновая запись включена в
  настройках Windows.

## Допущения

- Для погоды в утреннем брифинге заданы широта и долгота на вкладке «Интеграции»; если их
  нет или сеть недоступна, брифинг просто пропускает погоду.
- Telegram-контакты и Discord webhooks задаются как JSON в `config.json`; UI сейчас хранит
  Discord webhooks и Telegram-токен в конфиге, если системный keyring не настроен.
- Windows UserNotificationListener считается экспериментальным: при недоступности `winsdk`
  Джарвис читает последние сообщения Telegram-бота, если настроен токен.
