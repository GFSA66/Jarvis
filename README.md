# Jarvis — голосовой ассистент для Windows

Скрипт слушает микрофон, распознаёт русскую речь и по ключевым словам
запускает игры, приложения, сайты, музыку, делает заметки и т.д.
Работает в бесконечном цикле: сказал команду → Jarvis показал всплывающее
уведомление в правом нижнем углу экрана и (опционально) озвучил ответ.

---

## 1. Требования

- **Windows** (используются `win32gui`, `os.startfile`, `taskkill`, `shutdown`).
- **Python 3.8+** (в коде используется `:=`, walrus-оператор).
- Работающий **микрофон**.
- Интернет — нужен для распознавания речи (Google Speech API через
  `speech_recognition`) и для поиска треков.

### Python-пакеты

Установи одной командой:

```bash
pip install SpeechRecognition pyaudio pyautogui pywin32 pyttsx3 ytmusicapi
```

Если обычный `pyaudio` не ставится или ловит ошибки с микрофоном/устройствами
записи — используй `pyaudiowpatch` (форк с поддержкой WASAPI loopback):

```bash
pip install pyaudiowpatch
```

Скрипт сам подставит его вместо `pyaudio`, если он установлен (см. начало файла).

Пакеты `pyttsx3` и `ytmusicapi` — опциональные:
- без `pyttsx3` пропадёт только голосовая озвучка (попапы и текст в консоли останутся);
- без `ytmusicapi` не будет работать поиск конкретного трека по названию.

## 2. Настройка перед первым запуском

Все настройки — в виде констант в начале файла `jarvis.py`. **Обязательно
проверь и поправь пути под свою систему**, иначе соответствующие команды
не будут работать:

| Константа | За что отвечает |
|---|---|
| `GAME_PATH` | Путь к `GenshinImpact.exe` (сейчас не используется напрямую — запуск идёт через задачу планировщика, см. ниже) |
| `STEAM_PATH` | Путь к `Steam.exe` |
| `DISCORD_PATH` | Путь к `Discord.exe` |
| `TELEGRAM_PATH` | Путь к `Telegram.exe` |
| `MINECRAFT_LAUNCHER_PATH` | Путь к лаунчеру Minecraft |
| `PRISM_LAUNCHER_PATH` | Путь к `prismlauncher.exe` |
| `NOTES_PATH` | Куда сохранять заметки (по умолчанию — папка `Скрытая папка` в профиле пользователя) |
| `VOICE_ID` | ID голоса Windows для TTS (см. ниже, как его узнать) |

### Как найти `VOICE_ID`

При старте `pyttsx3` можно вывести список установленных голосов:

```python
import pyttsx3
engine = pyttsx3.init()
for v in engine.getProperty("voices"):
    print(v.id)
```

Скопируй понравившийся id (обычно вида
`HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Speech\Voices\Tokens\TTS_MS_RU-RU_...`)
и вставь в `VOICE_ID`.

### Запуск Genshin Impact через планировщик задач

Команда «геншин» выполняет:

```
schtasks /run /tn "GenshinLaunch"
```

То есть в Планировщике заданий Windows заранее должна быть создана задача
с именем **`GenshinLaunch`**, которая запускает `GenshinImpact.exe`
(это сделано, чтобы игра запускалась с правами администратора без UAC-запроса
каждый раз). Если такой задачи нет — команда просто не сработает.

### Steam-игры

Игры из словаря `GAMES` запускаются по протоколу
`steam://rungameid/<appid>` — Steam должен быть установлен и открыт
(или хотя бы зарегистрирован в системе как обработчик протокола `steam://`).
Чтобы добавить свою игру — найди её `appid` в URL страницы магазина
`store.steampowered.com/app/<appid>/...` и добавь пару `"название": appid`
в словарь `GAMES`.

### Chrome-профили

Скрипт использует конкретные профили Chrome:
- `MAIN_PROFILE_APP` → `--profile-directory=Default`
- `STUDY_PROFILE_APP` → `--profile-directory=Profile 2`

Проверь, что у тебя они действительно называются так (Chrome → `⋮` →
«Настройки» → «Вы и Google» → список профилей), либо поправь номер профиля
в коде.

## 3. Запуск

```bash
python jarvis.py
```

При старте появится уведомление «Джарвис слушает вас, господин.» —
после этого можно говорить команды. Список поддерживаемых слов и фраз можно
в любой момент вывести в консоль командой «список команд» или «что ты умеешь».

Чтобы остановить программу — скажи **«выход»**, либо `Ctrl+C` в консоли.

---

## 4. Режимы работы

### Пауза / возобновление
- **«огуречный салат»** — поставить Джарвиса на паузу (перестаёт реагировать
  на любые команды, кроме фразы возобновления).
- **«банановые кокосы»** — снять с паузы.

### Учебный / игровой режим
- **«скоро урок»** — включает учебный режим (`enjoing = False`).
- **«время игр»** — включает игровой режим (`enjoing = True`).

Некоторые команды (запуск игр, Steam, Discord, Roblox, фильмы, аниме,
выключение/перезагрузка ПК, переключение голоса и т.д.) работают **только
в игровом режиме** — это защита от случайного запуска игр во время учёбы.

## 6. Поиск и запуск конкретного трека

Команды `включи/поставь/найди трек/песню <название>` работают так:

1. Всё, что сказано **после** триггерной фразы, отправляется в поиск
   через библиотеку `ytmusicapi` (поиск работает без авторизации).
2. Берётся `videoId` первого найденного результата.
3. Открывается прямая ссылка `https://music.youtube.com/watch?v=<id>`
   в отдельном окне Chrome (`--app=...`), которое обычно начинает
   играть само; если нет — Jarvis дополнительно нажимает пробел.

**Ограничения:**
- Если пакет `ytmusicapi` не установлен — Jarvis честно скажет об этом
  голосом/попапом и не будет пытаться искать.
- Поиск без авторизации — «обезличенный» (не учитывает твою историю
  прослушиваний/лайки). Для персонализации нужно подключить файл
  авторизации `headers_auth.json` (см. документацию `ytmusicapi`) и
  передать его при создании клиента: `YTMusic("headers_auth.json")`.
- Это неофициальный API — Google теоретически может изменить внутренний
  протокол и временно сломать поиск.

## 7. Уведомления

Всплывающее окошко в правом нижнем углу экрана держится ~2 секунды:
- **зелёный фон** — команда выполнена успешно;
- **красный фон** — ошибка (не нашёл файл, не тот путь, ничего не нашёл
  в поиске и т.д.).

Озвучка через `pyttsx3` дублирует текст попапа, если включён голос
(команда «голос» переключает; можно выключить, оставив только визуальные
уведомления).

## 8. Частые проблемы

| Проблема | Возможная причина |
|---|---|
| «Не нашёл ... по пути» | Неверный путь в константе — открой файл и поправь |
| Джарвис не слышит команды | Проверь, что микрофон выбран по умолчанию в Windows, и что нет фонового шума/музыки на полную громкость |
| Команда срабатывает не та | Проверь порядок `elif`-веток в коде: более специфичные фразы должны проверяться раньше общих (например, поиск трека — раньше, чем просто «песн») |
| Genshin не запускается | Проверь, что в Планировщике заданий Windows создана задача `GenshinLaunch` |
| Discord не закрывается | Скрипт сначала гасит `Update.exe`, потом `Discord.exe` — если Discord всё равно перезапускается, увеличь `sleep` между `taskkill`-ами |
| Поиск трека не работает | Проверь, установлен ли `ytmusicapi` (`pip show ytmusicapi`), и есть ли интернет |

---

## 9. Безопасность и осторожность

- Команды «выключи пк» и «перезагрузи пк» реально выключают/перезагружают
  систему без подтверждения (`shutdown /t 0`) — учитывай это, находясь
  рядом с работающим микрофоном.
- Скрипт открывает **только** сайты из явного списка `SITES` — специально
  сделано так, чтобы случайно расслышанная фраза не превратилась в
  произвольный URL.
