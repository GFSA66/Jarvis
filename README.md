# Джарвис

Голосовой ассистент для Windows (русский язык): запускает игры и программы, открывает сайты,
включает треки в YouTube Music, ведёт заметки.

## Запуск на любом ПК

```
git clone <репозиторий>
cd jarvis
start.bat
```

При первом запуске `start.bat` сам создаст `.venv` и поставит зависимости (нужен Python 3.10+).

Что найдено на этом ПК, покажет:

```
.venv\Scripts\python jarvis.py --check
```

## Сборка в exe

```
build_exe.bat
```

Получится `dist\Jarvis.exe` (без консоли, с иконкой `jarvis.ico`; файл должен лежать рядом с `build_exe.bat`). Особенности:

- `config.json` кладётся **рядом с Jarvis.exe**, а не внутрь сборки: путь определяется по самому exe.
- Ошибки пишутся в `%USERPROFILE%\.jarvis\errors.log`, так как консоли нет.
- «Что ты умеешь» открывает `commands.txt` в блокноте, `Jarvis.exe --check` покажет `check.txt`.
- Готовый exe можно запускать на другом ПК без Python, пути определятся там заново.
- Если exe блокирует антивирус или SmartScreen, это типичная реакция на PyInstaller и `pyautogui`.
  Тогда запускайте через `start.bat`.

## Голос и нейросеть

Джарвис озвучивает ответы голосом Windows (SAPI). Проверить голос: кнопка **«Проверить голос»** в настройках (вкладка «Общие»)
или `.venv\Scripts\python jarvis.py --say "проверка"`. Список голосов: `--list-voices`. Если звука нет, причина записана в
`%USERPROFILE%\.jarvis\errors.log`. Для русской речи нужен русский голос: Параметры → Время и язык → Речь.

**Нейросеть** отвечает на вопросы голосом и коротко: «Джарвис, какую игру мне лучше поиграть?», «Джарвис, какая сегодня погода?».

1. Открой настройки → вкладка **Нейросеть**, нажми «Получить ключ» (Gemini: Google AI Studio, карта не нужна) и вставь ключ.
2. Нажми «Проверить», затем «Сохранить» и включи переключатель.
3. Говори фразу со словом «Джарвис». Без обращения нейросеть молчит, чтобы разговоры рядом не тратили лимит бесплатного тарифа.

Нейросеть знает твой ПК: видеокарту, процессор, память, список установленных игр Steam и то, когда ты в них играл, время
и режим (игровой/учебный). Погоду берёт из Open-Meteo (бесплатно, без ключа) по городу из настроек.
Если не хочешь передавать данные о ПК, выключи переключатель «Рассказывать нейросети про мой ПК».

Фразы-команды («открой ютуб», «запусти кс2») работают как раньше: вопрос уходит нейросети, только если он начинается
с вопросительного слова («какой», «что», «как», «расскажи»…) или Джарвис не нашёл такой команды. Проверить из консоли:
`.venv\Scripts\python jarvis.py --ask "какая сегодня погода"`.

Ключ сохраняется в `%USERPROFILE%\.jarvis\config.json` открытым текстом, не выкладывай этот файл. Ключ можно задать и
переменной среды `JARVIS_AI_KEY`. Бесплатные тарифы имеют лимиты запросов и меняются, актуальные значения смотри у провайдера.
У бесплатного Gemini вне ЕС запросы могут использоваться для обучения моделей.

## Поиск в Google

Скажи **«загугли …»** или **«найди …»**, и в Chrome (основной профиль) откроется поиск Google по этому запросу.
Подойдёт и «найди в интернете …». Примеры: «загугли рецепт борща», «найди погоду в Днепре».
«Найди трек …» по-прежнему включает музыку, а не ищет в Google.

## Настройки

Скажи **«открой настройки»**, откроется окно (сделано на `customtkinter`, тёмная тема). Всё, что в нём сохранено, применяется сразу, без перезапуска. В таблицах есть поиск, у каждой записи кнопки ✎ (изменить, или двойной клик) и ✕ (удалить). `Ctrl+S` — сохранить.

| Вкладка | Что там |
|---|---|
| Мои команды | Фраза → ссылка, путь к программе/папке или команда (`notepad.exe`). «Обзор…» выбирает файл |
| Игры Steam | Фраза → Steam appid |
| Сайты | Фразы для «открой …» |
| Ссылки | Фильмы, аниме, GitHub, комплектующие, Classroom, Logika, Roblox |
| Нейросеть | Провайдер (Gemini / Groq / OpenRouter / свой), API-ключ, модель, город для погоды, кнопка «Проверить» |
| Общие | Голос, задержка выключения, слово-активатор, профили Chrome, задача планировщика для Genshin, **автозапуск Джарвиса**, фразы паузы и режимов |
| Пути | Ручные пути к программам, если автопоиск не нашёл |

Свои команды проверяются раньше встроенных: если фраза совпадёт со встроенной («музыка»), сработает твоя.

### Где хранятся настройки

`%USERPROFILE%\.jarvis\config.json` (папка доступна для записи всегда, настройки переживают пересборку exe и
обновление проекта из git). Рядом лежат `notes.txt` и `errors.log`.

Файлы читаются по очереди, следующий перекрывает предыдущий:
`config.json` рядом с программой → `~/.jarvis/config.json` → файл из переменной `JARVIS_CONFIG`.
Окно настроек пишет в `~/.jarvis/config.json` (или в `JARVIS_CONFIG`, если она задана).
Чтобы перенести настройки на другой ПК, скопируй этот файл.

Списки «Мои команды», «Игры Steam» и «Сайты» заменяют значения по умолчанию целиком. Благодаря этому удалённая
запись не возвращается. Остальное (голос, пути, ссылки) дополняет умолчания.

`config.example.json` — шаблон для ручной правки (например, чтобы положить свои Classroom/Logika в `config.json` рядом
со скриптом). Не указанные в нём ключи берутся по умолчанию. Дополнительно можно задать `voice.id` и `voice.rate`
(список голосов: `jarvis.py --list-voices`). В окне этих двух полей нет.

## Автозапуск через Планировщик заданий

Во вкладке **Общие → Планировщик заданий Windows** есть два переключателя:

- **Запускать Джарвиса при входе в Windows**: создаётся задача `JarvisAutostart` (запуск через 10 секунд после входа).
  В собранном exe она запускает `Jarvis.exe`, при запуске из исходников — `pythonw.exe jarvis.py` из `.venv`.
- **С правами администратора (без запроса UAC)**: задача идёт с высшими правами, поэтому Джарвис стартует без окна UAC
  и может запускать программы, которым нужен админ. Создать такую задачу можно только с подтверждением UAC: окно появится
  один раз, при нажатии «Сохранить».

Если exe потом переместить, окно настроек покажет предупреждение: нажми «Сохранить», и путь в задаче обновится.
Выключить автозапуск можно тем же переключателем (задача удаляется).

Джарвис не даст запустить себя вторым экземпляром (например, из планировщика и вручную одновременно).

Скрипт, который создаёт задачу, лежит в `%USERPROFILE%\.jarvis\autostart.ps1`. Проверить задачу можно в «Планировщике заданий» (`taskschd.msc`).

## Как определяются пути

- **Chrome** — реестр (App Paths), Program Files, LocalAppData.
- **Discord** — через `Update.exe --processStart`, версия `app-X.Y.Z` не важна.
- **Steam** — реестр; игры запускаются через `steam://rungameid/<id>`.
- **Telegram, Minecraft, Prism, Genshin** — типовые папки на всех дисках.
- **YouTube Music** — ярлык PWA из меню «Пуск», иначе Chrome `--app`.
- Нет Chrome — ссылки открываются в браузере по умолчанию.

## Безопасность

- Выключение и перезагрузка идут с задержкой (по умолчанию 15 с), «отмена» их останавливает.
- «Выход» срабатывает только на целое слово, не на «выходной».
- Распознавание речи идёт через Google (онлайн): всё, что слышит микрофон, уходит на сервер.
- Вопросы к нейросети (и данные о ПК, если включено) уходят выбранному провайдеру.
  Включи `wake_word`, чтобы команды выполнялись только после «Джарвис».
